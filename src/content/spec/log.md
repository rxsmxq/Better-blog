# 站点更新日志

<!--
  格式约定（每条日志一个 ## 区块）：

  ## 更新标题

  - 日期：YYYY-MM-DD
  - 类型：feat | fix | style | refactor | chore
  - 页面：home / archive / list（页面标识，多个用 / 分隔，可用标识见下）
  - 简述：卡片上显示的一句话

  这里是详情正文（弹窗中显示），支持多段落，空行分段。

  可用页面标识（见 src/utils/changelog.ts 的 PAGE_META）：
    home 首页 / archive 归档页 / list 文章列表 / categories 标签图谱
    friends 友链页 / gallery 相册页 / guestbook 留言板
    post 文章详情页 / about 关于页 / site 全站

  可用类型：
    feat 新功能 / fix 修复 / style 样式 / refactor 重构 / chore 杂项

  最新记录写在最上面。
-->

## 示例：换上你自己的第一条更新

- 日期：2026-09-21
- 类型：chore
- 页面：site
- 简述：更新日志已清空，这一条是示例，照着它写就行

这是更新日志的示例条目。复制上面的区块，改掉标题、日期、类型和正文，就能添加一条自己的更新记录。

确认过格式之后，把这一条删掉即可；没有任何条目时，关于页的更新日志区域会自动留空。
